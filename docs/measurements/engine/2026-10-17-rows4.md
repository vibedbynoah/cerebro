# Four-row Q8_0 decode kernel (switch `cpu_rows4`): measured slower, stays off

Qwen3-0.6B-Q8_0, CPU decode, 128 tokens after a 32-token prompt, 16 threads, i9-12900H, quiet machine
(7.8% CPU before the run). Off/on alternated three times so thermal drift hits both; 3 reps each.
Raw: `rows4.jsonl`, `rows4-llamacpp.jsonl`. Script: cerebro-engine `tools/bench-rows4.cmd`.

| configuration              | runs (tok/s)        | median |
|----------------------------|---------------------|--------|
| Cerebro, rows4 off          | 59.6, 62.5, 62.3    | 62.3   |
| Cerebro, rows4 on           | 57.9, 58.4, 58.1    | 58.1   |
| llama.cpp b10751 (control)  | 70.7, 71.7, 71.8    | 71.7   |

Rows4 costs 7%. The 13% gap to the control is not in the dot product (both kernels read the same
bytes); next suspect is per-matvec dispatch and barrier cost (~200 pool dispatches per token).
