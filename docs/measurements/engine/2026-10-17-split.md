# GPU/CPU layer split (placement.rs): measured

i9-12900H, RTX 3070 Ti Laptop 8 GB, 32 GB RAM, NVMe. Greedy, 64 tokens after an 11-token prompt
(cerebro-engine `examples/greedy.rs`; `tools/split-check.cmd` for the correctness runs).

| model | placement | decode tok/s |
|---|---|---|
| Qwen3-14B Q4_K_M (8.4 GiB, does not fit 8 GB) | CPU only | 3.2 |
| same | auto split: 31/40 layers on the GPU (6.3 GiB), 2.4 GiB on the CPU | **11.8** |
| Qwen3-0.6B Q4_K_M | CPU only / forced 14/28 split / whole GPU | 70.1 / 101.4 / 263.0 |

Correctness: Qwen3-0.6B Q4_K_M greedy output is identical on CPU only, whole GPU and the 14/28 split
(48 tokens). Q8_0 and the 14B diverge from the CPU path at near-ties (CPU and whole-GPU already
differ there for Q8_0), not at the split.
